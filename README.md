This repository contains both application code and deployment tools to manage applications on Kubernetes clusters and synchronize them with a remote Git repository. It includes application code, Helm charts, ArgoCD manifests, and GitHub workflows for CI/CD. To deploy, run terragrunt run-all apply to create all infrastructure and deploy applications. Then configure kubectl for your clusters with aws eks update-kubeconfig commands for each environment. Terragrunt first initializes Terraform by downloading providers (AWS, Kubernetes, Helm) and modules (e.g., EKS, VPC), then builds a dependency graph to determine the order of deployment—VPC is created first, followed by EKS clusters, node groups, and built-in add-ons. Terraform generates authentication tokens for Kubernetes and Helm providers, after which namespaces for dev, staging, and prod are created. IAM roles and policies are applied for resources like Cluster Autoscaler and AWS Load Balancer Controller, with corresponding Kubernetes ServiceAccounts linked via IRSA. Helm charts, such as the AWS Load Balancer Controller, are installed, and ArgoCD projects and applications are deployed automatically. After deployment, you can verify cluster health, node readiness, pod status, and load balancer IPs using kubectl and AWS CLI commands. Git commits trigger GitHub Actions workflows, which update images and deploy changes through ArgoCD, ensuring continuous delivery across environments.
